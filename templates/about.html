Project Architecture & Theory

1. Background & Computer Vision Motivation

Image spam (unsolicited promotional advertisements, scam banners, phishing graphics, counterfeit vouchers) embedded in emails or web feeds bypass traditional textual keyword filters because spam texts are embedded directly inside pixel data. In DS307 Computer Vision (Unit 4: Classifiers), classical histogram-based classification provides an interpretable, highly efficient probabilistic technique to classify images based on class conditional feature distributions.

2. Mathematical Formulation: Bayes' Decision Rule

Given an input image $I$, we seek the posterior probability that $I$ belongs to the Spam class ($C = \text{Spam}$) versus the Legitimate/Ham class ($C = \text{Ham}$):

P(Spam | I) = [ P(I | Spam) × P(Spam) ] / P(I)

Where:

  • P(Spam) is the Prior Probability: our initial belief before examining the image.
  • P(I | Spam) is the Class-Conditional Likelihood: the probability of observing the image's feature distributions given that it is spam.
  • P(I) is the Total Evidence: $P(I | \text{Spam})P(\text{Spam}) + P(I | \text{Ham})P(\text{Ham})$.
3. Class-Conditional Feature Histograms

To evaluate $P(I | C)$, we discretize visual feature spaces into multi-dimensional histograms:

  1. Quantized 3D RGB Color Histogram ($16 \times 16 \times 16 = 4,096$ bins): Captures fine-grained RGB distributions. Spam images concentrate in vivid, primary, and saturated color regions.
  2. 2D Hue-Saturation Histogram ($18 \times 16 = 288$ bins): Decouples chromaticity (Hue) and purity (Saturation) from lighting intensity (Value).
  3. 1D Edge Gradient Histogram ($16$ bins): Computed via Sobel operator $\sqrt{I_x^2 + I_y^2}$. High gradient magnitude counts correspond to sharp synthetic typography and banner outlines.
4. Laplace (Additive) Smoothing

In empirical histogram estimation, an unseen color or gradient bin in a test image would yield a count of $0$, resulting in a zero probability $P(b | C) = 0$ and $-\infty$ log-likelihood. To prevent zero-frequency traps, we apply Laplace smoothing:

P(b | Class) = [ Count(b) + α ] / [ Σ Count(k) + α × K ]

Where $\alpha = 1.0$ is the smoothing parameter and $K$ is the total number of histogram bins.

5. Pixel-Wise Bayesian Spam Likelihood Heatmap

For each pixel $p(x, y)$ in the test image, the Bayesian classifier evaluates the local posterior probability:

P(Spam | p) = [ P(p | Spam) × P(Spam) ] / [ P(p | Spam) × P(Spam) + P(p | Ham) × P(Ham) ]

This produces a 2D spatial heatmap overlaid onto the image with a pseudo-color JET map. It visually localizes exactly which regions (e.g. bright neon "BUY NOW" buttons or discount banners) contributed to flagging the image as spam!
